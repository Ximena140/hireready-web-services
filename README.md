##Descripción del Proyecto##

HireReady es una plataforma orientada a la preparación de entrevistas laborales mediante simulaciones interactivas. El sistema permite a los usuarios practicar entrevistas, responder preguntas técnicas y recibir retroalimentación sobre su desempeño para mejorar sus habilidades profesionales.

##Características Principales##
Registro e inicio de sesión de usuarios.
Gestión de perfiles profesionales.
Registro de habilidades y experiencia.
Simulaciones de entrevistas.
Preguntas categorizadas por dificultad.
Evaluación automática de respuestas.
Retroalimentación personalizada.
Resultados y recomendaciones finales.
